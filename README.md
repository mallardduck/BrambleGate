# gh-pages

Source for BrambleGate's GitHub Pages landing site
(`https://mallardduck.github.io/BrambleGate/`). This branch has no shared history with
`main` — it's an orphan branch, same as the app source's `dirio` sibling project. Content
is hand-written static HTML/CSS for now; a future pass may move the `docs/` content from
`main` here and generate the site with a doc-generator tool instead.
